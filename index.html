How to edit

  1. Change the site title: edit the <title> tag in the <head>.
  2. Change the header name: edit the <h1> near the top of the <body>.
  3. To add a new page, create about.html and link to it from the nav.
  4. To add images, create a folder named images and use <img src="images/yourfile.jpg">.
